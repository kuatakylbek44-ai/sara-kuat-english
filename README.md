# Сара Қуат · English Teacher

Ағылшын тілі мұғалімі Сара Қуаттың қазақша және ағылшынша жеке сайты.

**Сайт:** https://kuatakylbek44-ai.github.io/sara-kuat-english/

## Мүмкіндіктер

- Телефон, планшет және компьютерге бейімделген дизайн.
- Қазақша / English тіл ауыстырғышы.
- Жұмсақ анимациялар және қозғалысты азайту баптауын қолдау.
- Instagram, WhatsApp, қоңырау және email сілтемелері.
- Білім, тәжірибе және ағылшын тілін оқыту тәсілдері.

## Жергілікті іске қосу

Сайтқа жинақтау немесе қосымша пакеттер орнату қажет емес.

```sh
python -m http.server 8080
```

Браузерде http://localhost:8080 мекенжайын ашыңыз.

## Өзгерту

Беттің құрылымы — `index.html`, дизайн — `styles.css`, аудармалар мен интерактивтер — `app.js`. Фото және белгіше `assets/` бумасында.

GitHub Pages `main` тармағының түбірінен жарияланады. Өзгерістерді `main` тармағына жібергеннен кейін сайт автоматты түрде жаңарады.

Мазмұн берілген түйіндемелер негізінде дайындалды. Фото иесінің портфолиосына арналған. Бастапқы түйіндемелердегі үй мекенжайы, туған күні және ұсыныс берушілердің байланыстары жарияланбайды.
